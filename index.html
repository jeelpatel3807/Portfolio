Independent Research Project • 2026–Present

Enhancing Fake News Detection via SBERT and TF-IDF Feature Fusion

Read Full Breakdown

Core Research Motivation

Natural language deception detection often suffers from a fundamental trade-off: traditional bag-of-words / TF-IDF methods capture specific deceptive terminology and domain keywords but miss nuanced semantic context. Conversely, dense contextual embeddings (such as Sentence-BERT) capture contextual meaning but can dilute crucial lexical cues.

This project investigates a late feature fusion strategy: concatenating dense 384-dimensional Sentence-BERT embeddings with high-discriminative TF-IDF n-grams (up to 5,000 features), subsequently feeding the merged representation into regularized linear and ensemble classifiers.

Transformer + Statistical Fusion Jointly preserves contextual intent and critical deceptive keywords.
Empirical Evaluation Protocol Validated across standard benchmarks using stratified splits, accuracy, precision, and recall.

Architecture Overview

01
Text Preprocessing Noise removal, lowercasing, and length standardization
02
Dual-Stream Feature Extraction Stream A: `all-MiniLM-L6-v2` (384-d) • Stream B: TF-IDF (1-2 ngrams)
03
Feature Space Concatenation Sparse-to-dense aligned concatenation matrix
04
Multi-Model Classification Logistic Regression, Linear SVM, and Random Forest comparison
